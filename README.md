# LIVESTOCK

Livestock is a portfolio value tracker. Usage:

```
Usage: livestock [OPTIONS] --file <FILE>

Options:
  -f, --file <FILE>          The JSON configuration file
      --days <DAYS>          The number of days to look back [default: 10]
      --debug                Prints additional debug information
      --extend-price         Extends the last known price in case no data exists
      --display-daily-value  display the daily portfolio value
  -b, --broker-match <BROKER_MATCH>
                             Filter brokers using a regular expression
      --asset-class-match <ASSET_CLASS_MATCH>
                             Filter asset classes using a regular expression
      --broker-list          List the brokers in the configuration file
      --asset-class-list     List the asset classes in the configuration file
  -h, --help                 Print help
  -V, --version              Print version
```

Broker and asset-class filters can be combined. For example,
`livestock --file stocks.json --broker-match 'Broker A' --asset-class-match 'equity|fund'`
includes instruments matching both filters.

Use `livestock --file stocks.json --asset-class-list` to list configured asset
classes.

```
{
    "Yahoo": [
        {
            "description": "I have bought these long time ago",
            "symbol": "AAPL",
            "quantity": 50,
            "buy_date": "2022-11-22",
            "sell_date": "2024-11-21"
        },
        {
            "symbol": "AAPL",
            "quantity": 100,
            "buy_date": "2022-11-22",
            "sell_date": "2024-11-21"
        },
    ],
    "XFRA": [
        {
            "symbol": "DE0001102408",
            "quantity": 1000,
            "buy_date": "2022-11-22",
            "sell_date": "2024-11-21"
        }
    ]
}
```
